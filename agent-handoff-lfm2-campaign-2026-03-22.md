## What Was Attempted And Why

The goal was to test whether a small set of LFM2-inspired architecture ideas
could beat the current local MLX Muon baseline under the same short benchmark:

- add `SwiGLU` as an MLP alternative
- add a gated short-convolution operator
- allow attention/conv block-pattern mixes such as `CACA`
- optionally scale depth and conv kernel size once a depth-4 winner exists

The reason for the campaign was simple: the March plans left open whether the
next gain would come from optimizer tuning or architecture changes. This
campaign tested the architecture side directly.

## Practical Recommendation: E3 vs E7 vs PR Timing

Recommendation:

- keep `E3` as the default architectural follow-up
- keep `E7` as an optional best-loss-at-higher-cost variant

Why `E3` is the better default:

- better than baseline by a comfortable 3-seed margin
- lower complexity than `E7`
- closer to the original model size/regime
- easier to defend in an upstream review

Why `E7` is still useful:

- it is the best raw-loss result
- it proves the architecture family scales in a favorable direction

PR timing:

- before the 3-seed run, an upstream PR would have been too early
- after the 3-seed run, a PR is now defensible
- however, the current branch is stacked on earlier bench-infra work and
  includes docs/results commits, so a clean upstream PR should probably be cut
  from a narrower branch
- if opening an upstream PR, `E3` is the better first candidate than `E7`
